# 素材契约与 docx 解析规则

以 264 期（20261003-1009）为实证样本。期目录结构：

```text
<期目录>/
  264期 20261003-1009.docx          # 原始文字稿（含注音）——排版不用
  去注音264 期 20261003-1009.docx   # 去注音版（排版必用此版）
  264 期周报文章封面.png             # 图文横幅封面
  264 期周报视频封面 16-10.png      # 视频封面，图文不使用
  图包/
    新作/{N}_{标题}/新作_N_图片_i.png|jpg   （可能含 视频_i.mp4，忽略）
    汉化/{N}_{标题}/汉化_N_图片_i.*
    周边/{N}_{标题}/周边_N_图片_i.*
  字幕/、视频成品及其工程/、音频及其工程/   # 视频链路，图文不使用
```

## docx 解析规则

| 规则 | 说明 |
| --- | --- |
| 选档 | **必须用标题带「去注音」的 docx**（如「去注音264 期 20261003-1009.docx」）；跳过 `~$` 临时文件。原始稿含 `【Hayase Yuu】` 之类注音括号，直接排版会漏进正文；目录内无去注音版时脚本告警并回退原始稿，**此时必须人工清除全部【注音】或向制作方要去注音版后才能上线**。正文检出【…】残留也会告警 |
| 首段 | `N期 <周期>`，解析期号与周期（如 `264期 20261003-1009`） |
| 次段 | 副标题，作为拟制标题的素材（`title_status=proposed`，需人工定稿） |
| 章节标题 | 段落样式 `2`，或文本命中图包章节目录名（新作/汉化/周边）；映射为 新作资讯/汉化情报/周边信息 |
| 新闻小标题 | 段落样式 `3`（或加粗段）；按章节内序号匹配图包 `N_` 目录，标题相似度 <0.9 时告警 |
| 正文段 | 常规样式段；整段纯 URL 的段丢弃；段尾粘贴的外链剥离（发布版不含外链） |
| 小标题清洗 | 剥离前缀「（简）」与首尾空白 |
| 署名段 | docx 一般不含；`credits` 为空时告警 → 用 `scripts/fetch_staff.py <期号> --apply <期目录>` 从飞书「周报工作表」拉取后人工核对（链路见 [feishu-staff-table.md](feishu-staff-table.md)） |
| 匹配兜底 | 序号匹配失败时按标题相似度（≥0.5）模糊匹配；NFKD 归一化后比较（兼容 ヴ/ウ+゛ 等组合记号差异） |

## 图包契约

- 一章一目录，目录名 `{N}_{标题}` 与 docx 小标题对应（N 从 1 连续编号）；
- 文件命名 `{章节}_{N}_图片_{i}.{png,jpg}`，按序号排序即为候选顺序；
- 候选图 >2 时 warnings 记录「默认取前 2 张」；
- 图片存在性在 build 阶段强校验，缺失即中止。

## 已知变体与处理

- 「（简）」前缀：图包目录名保留、docx 小标题保留、发布版小标题剥离（与 264 期线上一致）；
- 注音：原始 docx 含 `【Hayase Yuu】` 之类注音括号，**排版必须用去注音版**；只有原始稿时脚本告警，人工清除全部【注音】后才能上线；
- 期号不在首段时告警，不阻塞，由人工在 article.json 修正；
- 章节外杂段（如误留的说明文字）记入 warnings 并忽略，不进入正文。
